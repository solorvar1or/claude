# Swipe file — копилка залетевших постов

Каждый разобранный чужой пост — файл `YYYY-MM-DD-автор-тема.md` по шаблону ниже.
Раз в неделю Claude ищет общие паттерны и предлагает новые правила в `brand/rules.md`.

## Шаблон разбора
```
# @автор — [тема]
Ссылка:

Метрики на момент разбора: views / likes / replies / reposts
Подписчиков у автора:
Коэффициент залёта: likes / подписчики (x100) =

## Текст
(дословно)

- Почему залетел (3 причины):
- Время публикации и контекст (новость дня?):
- Что в ответах (о чём спорят):
```
