# itsnot.eth — контент-завод для X

Это «мозг» аккаунта itsnot.eth в X (Twitter). Тематика: Polymarket + ИИ.
Здесь лежат персонаж, правила текста, трекинг и процедуры. Claude работает строго по этим файлам.

## Главные правила для Claude
1. **Общаемся с владельцем на русском. Посты пишем на английском.**
2. Перед созданием любого поста **обязательно прочитать** `brand/persona.md`, `brand/voice.md`, `brand/rules.md`.
3. Никогда не выдумывать цифры, коэффициенты, объёмы, события. Если данных нет — спросить владельца или поставить `[ПРОВЕРИТЬ: ...]`.
4. Каждый пост должен содержать **человеческий ингредиент** (мнение, ставку, личный опыт, ошибку владельца). Без него пост не публикуем — спрашиваем владельца.
5. Любое новое правило, которое владелец озвучил («больше так не пиши», «вот так нравится») — **сразу записать** в нужный файл `brand/` и в `brand/changelog.md`. Система должна учиться.
6. Не давать финансовых советов. Персонаж делится своими ставками, а не говорит «покупайте».
7. После любой работы — коммит с понятным описанием, чтобы ничего не терялось.

## Команды владельца
| Владелец пишет | Что делаем | Скилл |
|---|---|---|
| «новый пост», «пост про …», «/new-post» | Создаём пост по правилам | `.claude/skills/new-post` |
| «анализ дня», «/daily-review» | Ежедневный разбор: наши метрики + чужие залёты | `.claude/skills/daily-review` |
| «разбери пост …», «/analyze-post» | Разбор чужого/своего поста: почему залетел | `.claude/skills/analyze-post` |
| «итоги недели», «/weekly-review» | Недельный отчёт, выводы, правки правил | `.claude/skills/weekly-review` |
| «режим degen / friendly / official …» | Переключить тон (см. `brand/voice.md`) | — |
| «новое правило: …» | Записать правило в `brand/` + changelog | — |

## Карта файлов
- `brand/persona.md` — персонаж itsnot: кто он, история, фразы, чего никогда не делает
- `brand/voice.md` — режимы тона (official / friendly / degen / …) с примерами
- `brand/rules.md` — правила написания постов, хуки, анти-ИИ чеклист
- `brand/changelog.md` — журнал изменений правил (что и почему поменяли)
- `content/formats.md` — рубрики и форматы постов
- `content/drafts/` — черновики
- `content/posts.csv` — все опубликованные посты + метрики
- `tracking/accounts.md` — список аккаунтов, за которыми следим
- `tracking/swipe/` — «копилка» чужих залетевших постов с разбором
- `tracking/daily/` — ежедневные отчёты
- `tracking/growth.csv` — подписчики и охваты по дням
- `tracking/scoreboard.csv` — табло Human vs AI (все ставки itsnot и yesbot)
- `playbook/` — стратегия, распорядок, старт на Polymarket

## Ограничения среды
Claude не имеет доступа к X напрямую (X блокирует ботов). Данные о постах владелец приносит сам:
скриншоты, ссылки с текстом, экспорт X Analytics (CSV). Claude разбирает и складывает в трекинг.
