# Новый пост

## Шаг 1. Загрузить правила (обязательно, каждый раз)
Прочитать: `brand/persona.md`, `brand/voice.md`, `brand/rules.md`, `content/formats.md`,
последние 10 строк `content/posts.csv` и последние записи `brand/changelog.md`.

## Шаг 2. Уточнить вводные (только то, чего не хватает)
- **Тема / событие / рынок.** Нет темы — предложить 3 идеи из рубрик, которые давно не выходили.
- **Режим тона.** Не указан — выбрать по таблице в `voice.md` и сказать какой.
- **Данные.** Цифры рынка (%, ¢, объём) — только от владельца (скрин/ссылка). Иначе `[ПРОВЕРИТЬ: ...]`.
- **Человеческий ингредиент.** Нет мнения или ставки владельца — задать ОДИН вопрос: «Какая твоя позиция / ставка?»

## Шаг 3. Написать 3 варианта
Каждый вариант — с другим типом хука (см. `rules.md` раздел 2). Формат ответа:

```
Рубрика: HYPE · Режим: deadpan

① [хук: противоречие] — N символов
<текст>

② [хук: цифра] — N символов
<текст>

③ [хук: признание] — N символов
<текст>

Визуал: <что приложить, например скрин графика рынка>
Первый ответ (ссылка): <текст + ссылка>
Лучшее время: <UTC>
Моя рекомендация: ② — потому что …
```

## Шаг 4. Самопроверка перед показом
- [ ] нет слов из анти-ИИ списка
- [ ] одна мысль
- [ ] ≤280 символов (если не тред / не длинный пост)
- [ ] есть человеческий ингредиент
- [ ] нет выдуманных цифр
- [ ] звучит как itsnot, а не как бот
- [ ] хук не повторяет тип хука последнего поста

## Шаг 5. После выбора владельца
- Сохранить черновик в `content/drafts/YYYY-MM-DD-тема.md` (все варианты + выбранный + правки).
- Если владелец правил текст — понять, что именно ему не понравилось. Если это похоже на общее правило,
  спросить: «Записать как правило?» → при «да» обновить `brand/` + `brand/changelog.md`.
- После публикации (владелец скажет «опубликовал» + ссылку) — добавить строку в `content/posts.csv`.
- Закоммитить изменения.
