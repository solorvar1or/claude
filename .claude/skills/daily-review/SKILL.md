# Анализ дня

## Шаг 1. Собрать данные у владельца
Попросить одним сообщением (что есть — то есть):
1. Скрин или цифры X Analytics: подписчики, показы, лучшие посты за день (или CSV-экспорт).
2. Метрики своих постов за сегодня (views / likes / replies / reposts).
3. 3–5 залетевших постов в нише (ссылка + текст + скрин с метриками). Источник — список «itsnot watch» в X.
4. Что обсуждают сегодня в ИИ и на Polymarket (если заметил).

## Шаг 2. Обновить трекинг
- `tracking/growth.csv` — строка за сегодня.
- `content/posts.csv` — метрики наших постов.
- Каждый чужой залетевший пост → файл в `tracking/swipe/` по шаблону оттуда.
- Новые интересные аккаунты → `tracking/accounts.md`.

## Шаг 3. Анализ
- Сравнить с прошлыми днями: рост или падение, и почему (рубрика, время, хук, режим, визуал).
- Какие рубрики и хуки дают лучший показатель `likes / impressions` и `new_follows`.
- Найти общее у залетевших чужих постов: эмоция, формат, время, привязка к новости.
- Не делать выводов по одному посту. Паттерн = минимум 3 наблюдения.

## Шаг 4. Отчёт
Создать `tracking/daily/YYYY-MM-DD.md` по шаблону `tracking/daily/_template.md`.
Владельцу в чате: коротко на русском — 3 главных вывода + план на завтра + предложения правок правил.
