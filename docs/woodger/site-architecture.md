# WOODGER — архитектура сайта

Мебель на заказ, Витебск. ООО «ВУДЖЕР».
Документ описывает структуру, контент, пользовательские пути, конверсию и SEO. Визуальный дизайн (цвета, шрифты, стили, анимации) здесь сознательно не рассматривается.

Обозначения:

- `[НУЖНО УТОЧНИТЬ У WOODGER]` — факт, который нельзя публиковать без подтверждения;
- `[УТОЧНИТЬ]` — решение по структуре зависит от ответа WOODGER;
- `[Плейсхолдер]` — место для конкретных данных проекта;
- **MVP / V2** — в какую версию сайта входит элемент.

Главный фильтр для каждого решения: *«Поможет ли это человеку выбрать WOODGER или оставить заявку?»* Если нет — элемента на сайте нет.

## 0. Исходные принципы

1. **Сайт продаёт не мебель, а уверенность в результате.** Мебель индивидуальная, цену на сайте не «купить». Человек покупает доверие: «они умеют, у них своё производство, я вижу реальные работы, понимаю, что будет дальше».
2. **Доказательства вместо утверждений.** Никаких «высокого качества» и «индивидуального подхода» без фото, видео, людей и проектов, которые это подтверждают.
3. **Портфолио — центр сайта.** Категории, главная и страница «О компании» ссылаются на проекты; проекты ведут к заявке.
4. **Заявка = начало разговора, а не анкета.** Минимум обязательных полей, возможность просто отправить фото помещения.
5. **Два физических места — сильный актив.** Салон (пр. Победы, 15) и производство (ул. Петруся Бровки, 22Б) — это то, чего нет у «посредников» и частных мастеров. Это должно быть видно на сайте.
6. **SEO через структуру, а не через тексты.** Каждый коммерческий запрос получает одну полноценную посадочную страницу с реальными проектами, ответами на вопросы и формой. Никаких тонких страниц «под ключ» и SEO-полотен.
7. **Без механик дешёвых мебельных сайтов:** никаких поп-апов на входе, таймеров акций, «колеса фортуны», «скидки 30% только сегодня», корзины и цен «от 99 руб.».

### 1.3. Основное меню

```
[Логотип WOODGER]   Мебель ▾   Проекты   Как заказать   О компании   Контакты     [телефон] [мессенджер]  [Рассчитать проект]
```

- 5 пунктов — максимум. «Мебель ▾» раскрывает категории (с одной реальной фотографией у каждой — опционально).
- Телефон кликабельный, мессенджер — прямой deep link (Viber/Telegram/WhatsApp — `[НУЖНО УТОЧНИТЬ, какие используются]`).
- На мобильном: меню + постоянная нижняя панель из 3 действий: **Позвонить · Написать · Расчёт**.

**Подвал:** все категории, Проекты, Как заказать, О компании, Контакты, Дизайнерам, адрес салона, адрес производства, режим работы, телефоны, соцсети, реквизиты ООО «ВУДЖЕР» (УНП `[НУЖНО УТОЧНИТЬ]`), Политика ПДн.

**Правило создания новой посадочной:** отдельная страница появляется только если (а) есть отдельный спрос, (б) есть минимум 3–4 реальных проекта для неё, (в) есть уникальные ответы на вопросы. Иначе это раздел на существующей странице.

**Технический минимум SEO (влияет на структуру):**

- ЧПУ-адреса латиницей, одна страница = один основной запрос, без дублей.
- Хлебные крошки на всех внутренних страницах + разметка `BreadcrumbList`.
- Разметка `LocalBusiness`/`FurnitureStore` для салона с адресом, телефоном, режимом работы; данные идентичны карточкам на Яндекс.Картах и Google Maps.
- Разметка `FAQPage` на категориях и «Как заказать» (для Яндекса полезна, в Google — без гарантий расширенного сниппета).
- Проекты — индексируемые страницы с уникальными title и alt у фото («Угловая кухня [материал фасадов] — проект WOODGER, Витебск»).
- Перелинковка: категория ↔ проекты этой категории ↔ «Как заказать» ↔ расчёт.
- Регистрация и верификация в Яндекс.Вебмастере и Google Search Console; карточки салона и производства в Яндекс.Бизнесе и Google Business Profile.

### 1.5. Чего НЕ делать

| Страница | Почему не нужна |
|---|---|
| Интернет-магазин / каталог товаров с ценами и корзиной | Продукт индивидуальный; каталог «готовых моделей» снижает восприятие уровня и создаёт ложные ожидания по цене |
| «Акции» | Работает на имидж дешёвого магазина. Если акция реально есть — одна строка на странице расчёта, без отдельного раздела |
| «Новости» | Без регулярного наполнения выглядит заброшенно и ничего не продаёт |
| Блог (в MVP) | Требует постоянного ресурса. Возможен в V2 только как полезные гиды (см. раздел V2) |
| Отдельные страницы «Доставка», «Оплата», «Гарантия», «Монтаж» | Всё это — части одного вопроса «как заказать». Собрано на `/kak-zakazat/` |
| Отдельная страница «Отзывы» (в MVP) | Отзывы сильнее рядом с проектами, к которым относятся. Отдельная страница — V2, когда отзывов много |
| «Вакансии» | Не влияет на заявку. Достаточно строки в подвале, если нужен найм |
| Страницы под каждый стиль и тип («кухни в стиле лофт», «прямые кухни», «кухни из МДФ») | Без проектов под каждую — это тонкие SEO-страницы. Решается фильтрами и разделами внутри категории. В V2 — только для групп с ≥4 проектами |
| Страницы городов области («мебель на заказ Новополоцк») | Только если WOODGER реально работает там `[УТОЧНИТЬ]` и есть проекты оттуда. Не в MVP |
| 3D-конструктор кухни | Дорого, даёт нереалистичные ожидания и «игровой» трафик вместо заявок |

## 2. Главная страница

Логика страницы повторяет путь посетителя:
**уровень работ → что делает WOODGER → реальные проекты → почему можно доверять → как проходит заказ → где нас найти → заявка.**

### Блок 1. Шапка

- **Цель:** навигация и постоянный доступ к контакту/расчёту с любого экрана.
- **Что видит пользователь:** логотип, меню (5 пунктов), телефон, иконку мессенджера, кнопку расчёта. При прокрутке — компактная закреплённая версия. На мобильном — нижняя панель «Позвонить · Написать · Расчёт».
- **Пример заголовка:** —
- **Пример текста:** —
- **CTA:** «Рассчитать проект» (основной), телефон, мессенджер.
- **Контент от WOODGER:** логотип в векторе, основной телефон, мессенджеры, режим ответа на звонки.

### Блок 2. Первый экран (Hero)

- **Цель:** за 3–5 секунд ответить на вопросы «что это», «где», «какого уровня», и дать два пути: смотреть или считать.
- **Что видит пользователь:** одна крупная профессиональная фотография лучшего реального проекта (не стоковая, не 3D-визуализация) или короткое беззвучное видео-петля из реального интерьера/производства. H1, подзаголовок, две кнопки, строка из 2–3 проверяемых фактов.
- **Пример заголовка (H1):** «Мебель на заказ в Витебске»
  Альтернатива с сохранением запроса: «Мебель на заказ в Витебске — от проекта до монтажа»
- **Пример текста:** «Проектируем и изготавливаем кухни, шкафы, гардеробные и другую мебель по размерам вашего помещения. Собственное производство на ул. Петруся Бровки, салон на проспекте Победы, 15.»
- **Строка фактов (только подтверждённое):**
  `Собственное производство в Витебске` · `Салон на пр. Победы, 15` · `[Гарантия — НУЖНО УТОЧНИТЬ У WOODGER]`
- **CTA:** основной — «Рассчитать мой проект»; второй — «Смотреть проекты».
- **Контент от WOODGER:** 1–3 лучшие профессиональные фотографии проектов (горизонтальная + вертикальная версия для мобильного), опционально видео 10–15 сек., подтверждение формулировок про «полный цикл» (проект, замер, производство, доставка, монтаж — `[НУЖНО УТОЧНИТЬ, что из этого делает WOODGER сам]`).

### Блок 3. Что мы делаем (категории)

- **Цель:** быстро распределить посетителя в нужную категорию и показать широту ассортимента; главный узел перелинковки на SEO-посадочные.
- **Что видит пользователь:** 5–7 карточек: фото реального проекта, название категории, одна строка уточнения. Каждая карточка — ссылка на категорию.
- **Пример заголовка (H2):** «Что мы изготавливаем»
- **Пример текста карточек:**
  - Кухни — «Под размеры, технику и привычки вашей семьи»
  - Шкафы — «Встроенные, распашные, купе — от пола до потолка»
  - Гардеробные — «Системы хранения в нишах и отдельных комнатах»
  - Гостиные — «ТВ-зоны, стеллажи, библиотеки» `[УТОЧНИТЬ]`
  - Ванные — «Тумбы и пеналы для влажных помещений» `[УТОЧНИТЬ]`
  - Корпусная мебель — «Прихожие, детские, спальни, кабинеты»
  - Для бизнеса — «Офисы, кафе, магазины» `[УТОЧНИТЬ]`
- **CTA:** сама карточка («Смотреть кухни →» и т. п.).
- **Контент от WOODGER:** подтверждённый список категорий; по 1 лучшей фотографии на категорию; перечень изделий внутри «корпусной мебели».

### Блок 4. Избранные проекты

- **Цель:** главное доказательство уровня. Перевести посетителя в портфолио — самый сильный вовлекающий раздел.
- **Что видит пользователь:** 4–6 проектов разных категорий. На карточке: фото, название проекта, тип помещения/район, 1 особенность («Кухня с островом и скрытой кладовой»). Ссылка на страницу проекта.
- **Пример заголовка (H2):** «Проекты, которые мы реализовали»
- **Пример текста:** «Каждый проект — под конкретное помещение и конкретных людей. Посмотрите, какие задачи решали наши клиенты.»
- **CTA:** «Смотреть все проекты» (вторичный); на карточке — «Подробнее о проекте».
- **Контент от WOODGER:** 4–6 проектов с полным набором данных (см. раздел 4), согласие клиентов на публикацию.

### Блок 5. Своё производство и салон (доказательство, а не «наши преимущества»)

- **Цель:** заменить типовой блок «почему мы» на проверяемые факты. Отличить WOODGER от посредников и частных мастеров.
- **Что видит пользователь:** два полуэкрана/две половины:
  1. **Производство:** фото/видео цеха, оборудования, людей за работой. 2–3 факта, только подтверждённые.
  2. **Салон:** фото салона, что можно там увидеть и потрогать (образцы фасадов, столешниц, фурнитуры — `[НУЖНО УТОЧНИТЬ, что есть в салоне]`), адрес.
- **Пример заголовка (H2):** «Изготавливаем сами — в Витебске»
- **Пример текста:**
  «Мебель WOODGER делается на нашем производстве на ул. Петруся Бровки, 22Б. Мы сами отвечаем за каждый этап: [перечень этапов — НУЖНО УТОЧНИТЬ]. А в салоне на проспекте Победы, 15 можно увидеть материалы и фурнитуру вживую и обсудить проект с [дизайнером/менеджером — НУЖНО УТОЧНИТЬ].»

## 4. Портфолио «Проекты»

### 4.1. Каталог проектов `/proekty/`

- **H1:** «Проекты WOODGER — мебель на заказ в Витебске»

  - Тип объекта: квартира, новостройка, дом, коммерческий объект.
  - Опционально (V2): стиль, особенности («до потолка», «с островом», «в нише»).
- **Карточка проекта:** главное фото; название проекта; тип мебели; тип объекта/район (если клиент не против `[УТОЧНИТЬ]`); одна строка — главная особенность.

Если исторических проектов с описанием мало, на старте допустимы «короткие» проекты (фото + карточка параметров + 2–3 предложения), но первые 4–6 должны быть полными.

## 5. Калькулятор / форма заявки

### 5.1. Принцип

Автоматический калькулятор с ценой на экране **не рекомендуется**: цены сильно зависят от материалов, а WOODGER ещё не дал ценовых данных. Неточная автоматическая цена либо отпугнёт, либо создаст ложное ожидание. Вместо этого — **короткий пошаговый сценарий «Предварительный расчёт»**, результат которого — звонок/сообщение специалиста с ориентировочной стоимостью.

Если WOODGER готов дать ценовые ориентиры (например, «кухня от X руб. за погонный метр» `[НУЖНО УТОЧНИТЬ]`), на V2 можно добавить вывод вилки на последнем шаге — только как ориентир с оговоркой.

### 5.2. Оптимальный сценарий: 3 шага + контакт

Прогресс-индикатор: «Шаг 1 из 4». Каждый шаг — один экран на мобильном. Переход без перезагрузки. Введённые данные сохраняются при возврате назад.

**Шаг 1. Что нужно?** *(обязательно)*
- Выбор одной или нескольких карточек: Кухня · Шкаф · Гардеробная · Гостиная/ТВ-зона · Ванная · Прихожая · Детская · Другое · Мебель для бизнеса.
- Если пользователь пришёл со страницы категории или проекта — шаг уже заполнен (можно изменить).

**Шаг 2. Помещение и размеры** *(всё необязательно, но с подсказкой, что ускоряет расчёт)*
- Прикрепить файлы: фото помещения, план/чертёж, проект дизайнера, обмерный план. Форматы: JPG, PNG, HEIC, PDF `[+ DWG — УТОЧНИТЬ]`; до 10 файлов `[лимит размера — определить технически]`.
- Размеры — одно текстовое поле: «Например: стена 3,2 м, потолок 2,7 м» (не набор полей длина/ширина/высота — он пугает и не подходит для угловых и сложных конфигураций).
- Чекбокс-альтернатива: «Размеров пока нет — нужен замер».
- Для кухни дополнительно (появляется только при выборе «Кухня»): планировка — прямая / угловая / П-образная / с островом / не знаю.

**Шаг 3. Пожелания** *(всё необязательно)*
- Референс: загрузка картинки «как нравится» или ссылка (Pinterest, Instagram и т. п.).
- Стадия ремонта: только планирую · идёт ремонт · ремонт закончен · новостройка без отделки. *(Помогает менеджеру понять срочность и когда звать на замер.)*
- Когда нужна мебель: как можно скорее · в течение 1–2 месяцев · позже · не знаю.
- Комментарий — свободное поле: «Что важно учесть».
- Ориентир бюджета — **в MVP не включать**. Вопрос о бюджете на раннем этапе часто снижает конверсию и раздражает; WOODGER узнает его в разговоре. Можно добавить в V2 как необязательный с диапазонами, если менеджеры попросят `[УТОЧНИТЬ]`.

**Шаг 4. Контакт** *(минимум обязательного)*
- Имя — обязательно (одно поле, без фамилии).
- Телефон — обязательно (маска +375). 
- Как удобнее связаться: звонок · Viber · Telegram · WhatsApp `[список уточнить]` — выбор по умолчанию «звонок».
- Удобное время для звонка — необязательно.
- Согласие на обработку персональных данных — обязательно (чекбокс + ссылка на политику).
- Текст рядом с кнопкой: «[Специалист] свяжется с вами [в течение … в рабочее время — НУЖНО УТОЧНИТЬ]. Ни к чему не обязывает.»
- Кнопка: **«Получить расчёт»**.

## 8. Пользовательские сценарии

### Сценарий 1. Ищет кухню через поиск
**Кто:** делает ремонт, точно знает, что нужна кухня, сравнивает несколько компаний.
**Путь:** Яндекс/Google «кухни на заказ Витебск» → `/kuhni/` → блок «Проекты кухонь», фильтр «Угловые» → страница проекта «Угловая кухня …» → читает решение и материалы → «Хочу похожий проект» → форма с переданным референсом → `/raschet/spasibo/`.
**Что удерживает:** проекты во втором блоке, детали конструкции, понятный ответ «от чего зависит цена».
**Запасной выход:** если не готов оставлять телефон — мессенджер с заготовленным текстом или «Записаться в салон».

### Сценарий 2. Владелец новостройки, не знает, с чего начать
**Кто:** получил ключи, нужна мебель «во всю квартиру», нет дизайнера и понимания процесса.
**Путь:** Instagram / сарафан → главная → «Что мы изготавливаем» → `/proekty/`, фильтр «Новостройка» → 2–3 проекта → «Как заказать» (понимает, когда звать на замер и что ремонт можно не заканчивать — `[УТОЧНИТЬ]`) → `/raschet/` → выбирает несколько категорий → прикрепляет план квартиры от застройщика → отмечает «Новостройка без отделки» → контакт.
**Что удерживает:** проекты в похожих квартирах, прозрачный процесс, возможность отправить план без размеров.

### Сценарий 3. Скептик, сравнивающий предложения
**Кто:** уже получил 1–2 расчёта, боится переплатить или нарваться на «посредника».
**Путь:** заходит на сайт по названию или из карт → «О компании» → видео производства, люди, материалы, контроль качества → отзывы со ссылкой на Яндекс.Карты → «Контакты» → «Записаться в салон», чтобы увидеть материалы вживую.
**Что удерживает:** доказательства собственного производства, реальные люди, реквизиты, салон, где можно пощупать образцы.

### Сценарий 4. Есть готовый проект или чертёж
**Кто:** клиент с дизайн-проектом или собственным эскизом; хочет понять цену.
**Путь:** главная → кнопка «Рассчитать проект» → шаг 2: загружает PDF/чертёж → шаг 4: контакт. Или: категория → «Отправить чертёж».
**Что удерживает:** явное обещание «рассчитаем по вашему проекту», поддержка нужных форматов файлов, обещанный срок ответа.

### Сценарий 5. Дизайнер интерьеров / архитектор
**Кто:** ищет надёжного производителя для своих клиентов.
**Путь:** подвал или «О компании» → `/dizajneram/` (или контакты) → смотрит проекты с пометкой «по проекту дизайнера», материалы и производство → «Отправить проект на расчёт» (форма с файлом и отметкой «дизайнер») или прямой контакт ответственного.
**Что удерживает:** профессиональные детали в проектах (материалы, фурнитура, конструктив), понятные условия `[УТОЧНИТЬ]`, указание имени дизайнера в проектах.

### Сценарий 6. Владелец бизнеса
**Кто:** открывает кафе/офис/магазин; важны сроки, договор, безналичный расчёт.
**Путь:** поиск «мебель для кафе на заказ Витебск» → `/dlya-biznesa/` → коммерческие проекты → «Запросить коммерческое предложение» (компания, тип объекта, срок открытия, ТЗ) → звонок.
**Что удерживает:** реальные коммерческие проекты, упоминание работы с юрлицами по договору `[УТОЧНИТЬ]`.

### Сценарий 7. Мобильный, локальный, «уже рядом»
**Кто:** нашёл «мебельный салон Витебск» в Яндекс.Картах, хочет зайти.
**Путь:** карточка на картах → сайт `/kontakty/` → проверяет режим работы и вход → «Построить маршрут» / звонок → визит в салон. Альтернатива — сразу звонок с нижней мобильной панели.
**Что удерживает:** фото входа, точный адрес и ориентиры, кнопки звонка и маршрута на первом экране.

### Сценарий 8. Возвращающийся посетитель, готовый к контакту
**Кто:** уже смотрел сайт, обсуждал с семьёй, вернулся.
**Путь:** главная → кнопка «Рассчитать проект» в шапке или мессенджер в нижней панели → короткий контакт.
**Что удерживает:** постоянный доступ к контакту без поиска; отсутствие мешающих поп-апов.

## 9. Система CTA

### 9.1. Иерархия

| Уровень | Функция | Пример | Правило |
|---|---|---|---|
| **Основной** | Начать заявку | «Рассчитать мой проект» | Один на экран. В шапке — всегда |
| **Контекстный** | Заявка, привязанная к содержанию страницы | «Хочу похожую кухню», «Отправить размеры», «Узнать стоимость моей кухни» | Формулировка повторяет то, что человек только что смотрел |
| **Мягкий / офлайн** | Для тех, кто не готов к заявке | «Записаться в салон», «Задать вопрос в Viber», «Позвонить» | Рядом с основным, но визуально слабее (детали — на этапе дизайна) |
| **Навигационный** | Удержание и перелинковка | «Смотреть проекты», «Все кухни», «Как мы работаем» | Ведёт к доказательствам, а не к форме |

| Для бизнеса | Запросить коммерческое предложение | Форма КП |
| Спасибо | Посмотреть проекты, пока ждёте | Портфолио |

### 9.3. Правила

- Не использовать «Оставить заявку», «Купить», «Заказать сейчас», «Успей», «Получить скидку».
- Глаголы — про результат для человека: рассчитать, обсудить, посмотреть, отправить, записаться.
- Не более одного основного CTA в пределах экрана.
- Никаких поп-апов при входе, при уходе со страницы и по таймеру. Онлайн-чат — только если на нём реально отвечают в рабочее время `[УТОЧНИТЬ]`; иначе — мессенджеры.
- Каждый CTA — отдельная цель в аналитике (клики tel:, мессенджеры, отправки каждой формы, маршрут), чтобы понимать, какие страницы реально приводят заявки.

### 2. Что можно убрать для MVP

- **Мебель для ванной / гостиной / бизнеса** — не делать отдельными страницами, пока нет 3+ проектов; поставить разделом на хабе «Корпусная мебель».

- **Дизайнерам** — заменить строкой в подвале и на «Контактах» («Дизайнерам и архитекторам: [e-mail/телефон]»), если программы сотрудничества пока нет.
- **Фильтры в портфолио** — оставить только «Тип мебели», если проектов меньше 15.
- **Блок отзывов** — убрать, пока нет реальных отзывов (ссылка на карточку Яндекс.Карт вместо него).
- **Видео** — допустимо стартовать с фото, если съёмка не успевает; hero и блок производства на фото.
- **Шаг 3 формы (пожелания)** — можно объединить со вторым шагом, если по аналитике будет заметен отвал.
- **Мультиязычность** — не нужна.

**Минимально жизнеспособный сайт:** Главная, Кухни, Шкафы, Корпусная мебель (хаб), Проекты (6–10 проектов), Как заказать, Расчёт + Спасибо, О компании, Контакты, Политика ПДн.

- Отдельные страницы для категорий, набравших проекты: гардеробные, гостиные, ванные, прихожие, детские (по правилу «≥4 проекта + спрос»).
